# ADR delta: where the implementation departs from F6

F6's reports are unchanged; this file records each departure and its evidence.
Status: IMPLEMENTED, DEFERRED or OPEN (needs an owner decision).

| ADR | F6 / original choice | Revised decision | Evidence | Status |
|---|---|---|---|---|
| ADR-JNL-01 | P0R now: production replay plus a resync guard; an incomplete tail with no later valid frame is still cut as torn (M-A1 direction). | Strict: an owner never cuts an uncertain tail. Any incomplete or invalid frame refuses unless there is independent boundary evidence, which v1 cannot supply; the only cut is an explicit `zeros3 journal salvage` that keeps the original. Read-only opens serve the prefix and report the tail. | X14 on the engine, 300 trials: P0R silent loss S3 3.7%, S3x 2.3%, S5 2.0%, S7 100%; strict 0% outside the S6 residual. Cost: crash refusals 50-56% (P0R 24-28%). `FB-01/results/x14_engine.jsonl`. | IMPLEMENTED in d2727f4; availability cost OPEN until markers and seal (M-C2) |
| E2 (checkpoint fallback) | 2337f48: a checkpoint that fails to verify or match is ignored and the whole journal replays; a damaged V4 falls back to V3, then V2. | A checkpoint that is present but damaged, foreign or contradicted refuses, by name and kind, with no fallback to an older layout. Rebuild only on the operator's salvage, which moves it into quarantine and keeps the journal whole. An open that skips the checkpoint still checks it against the journal. | F4-JNL-01: 14/40 at 2337f48, REFUSE now, also with the checkpoint off; `TestFB01ConflictingCheckpoint`; five older tests that relied on fallback now refuse, then salvage. | IMPLEMENTED in d2727f4 |
| M-A0 fault sites | A fault-injection build tag, compiled out of release builds, at every named fsync, write and rename site. | Nil function variables (`testJournalFault`, `testJournalPolicy`), the store's existing `testHook` convention, at five journal and checkpoint sites; no build tag. | M-A1 recovery modes | refuse, salvage-to-copy, truncate-with-proof, rebuild-from-packs. | refuse (default) and salvage (explicit cut on a copy, original kept, checkpoint rebuild) only. v1 offers no boundary proof, so truncate-with-proof would be a guess; rebuild-from-packs is not needed for any FB-01 case. | `TestFB01PartialMultiframeGroup`, `TestFB01ConflictingCheckpoint`. | DEFERRED |
| M-A0 fuzz in CI | Fuzz targets run in CI for a bounded time. | Targets exist and run bounded locally (30 s each, recorded). | Writer failure | A failed group write or fsync poisons the journal; the partial bytes stay on disk. | Also truncate back to the last acknowledged frame and fsync, so a clean reopen follows; if that fails the journal stays poisoned and the next open refuses. | `TestFB01WriterRollback` (ENOSPC short write, EIO fsync, failed rollback). | IMPLEMENTED in d2727f4 |
| ADR-JNL-01 (FB-01R) | Strict refusal of every damaged tail (d2727f4); boundary evidence deferred to markers and a seal (M-C2). | An ack watermark in a sidecar (`journal/visibility.ack`, Design A) bounds the acknowledged end. Damage at or below it, S6 included, refuses. v1 frames are kept; the v2 group-commit format (Design B) stays a test prototype because its zero-fsync mode loses a group inside its seal lag. | `FB-01R/results/x14r_engine.jsonl`, `design_b.jsonl`, `kill.jsonl`, `measure.jsonl`, `compat.jsonl`. | IMPLEMENTED in 015a2f1; default mode OPEN (owner) |
| M-A1 recovery modes (FB-01R) | refuse and salvage only (FB-01). | Adds truncate-with-proof: only a tail the watermark proves unacknowledged, moved to quarantine with its hash and proof before the cut. | `TestFB01RInterruptedGroupMatrix`, `TestFB01RTailDiscardInterrupted`. | IMPLEMENTED in 015a2f1 |
| E2 (FB-01R) | Any checkpoint whose body fails refuses (d2727f4). | A V4 generation whose CRC-checked trailer binds it to this store and journal prefix but whose body fails replays the whole journal; unreadable trailers, foreign files, contradictions and legacy layouts still refuse. | `TestNamespaceCheckpointRejectsInvalidFramesAndPrefix`, `TestFB01ReproF6JNL01` (`assertCheckpointRebuilt`, `fb01RebuildFromJournal`). | IMPLEMENTED in fb35ad4 |

| ADR-PUB-01 (FB-02 M-A5) | Compare a commit against the current version before publishing; skip when equivalent. | Only when the caller asks: `if_unchanged` on the commit (advertised in /info), `replicate -if-unchanged`, and authority import, which was always idempotent.
