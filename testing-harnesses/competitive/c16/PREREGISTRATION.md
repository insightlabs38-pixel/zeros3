# C16 · Transfer when the destination lacks native authority

Freeze a0ab61b as the native control. Price a single exact update with
an empty destination, a related ordinary object at the destination key,
an explicit ordinary object at another key in the same bucket, and
a receiver with prepared authority. Use the prepared TypeScript lane
and published negative controls. Extend to SQLite, dtype tensors,
independent model weights, shifted data and entropy. Compare ordinary
PUT, native CDC, scoped closure and local OpenXet where the interface
supports a matched trial.

Test whether a signed explicit same-bucket base can be prepared locally
from verified bytes within hard byte and CPU limits. Compare cheap
preparation, fully optimized source, transfer-only timing and end-to-end
timing. Any proposal must preserve byte identity and destination scope
through retries, unsupported peers, corrupt inputs and interruption.
Keep ordinary transfer fallback and account for retained dependencies.
Use loopback and bounded per-request delay and throughput models.
