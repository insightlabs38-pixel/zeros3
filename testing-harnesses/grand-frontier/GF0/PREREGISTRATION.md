# GF0 measurement plan

Freeze exact native costs for several independent families on the FB-16
engine. Compare recompressed CDC with the current archive optimizer
using structural forms, grouped records and sparse-file discovery in
separate paired stores. Reverse order on the repeat. Reuse FB-12 and
C13 matched record controls where their input identity and cost model
apply. Run only the measured corpus. Do not retune the optimizer here.

Prediction. Archive selection will lower retention on several histories,
with a read-cost frontier that differs by family. The near-empty entropy
search should preserve CDC, and any emitted expansion is evidence. For
the frozen panel, independently compare each recovered whole-body SHA
and sampled 4 KiB bytes with the input. Report exact filesystem blocks
after native archive finalization, and audit pack plus metadata charges.

Use resident input fixtures only during local test setup. The comparison
charges physical output, process CPU and wall. Reopen each store and
take a first-pass probe before deep verification, then repeat the probe
with ambient warm caches. Reopen is an ambient cache observation.
Each family uses at most three revisions and each trial uses one
disposable store. Keep the panel under 256 MiB of input and two CPUs.

GF1 will test a constrained exact oracle and two different searches.
The critical alternative to C19 is to retain nonseparable pack and read
charges throughout search rather than correcting them only after
per-component choices. GF2 will compare compiled compressed-domain
ranges with exact witness/replay checkpoints. GF3 will compare bounded
multi-source programs with mined shared phrases under the same closure
and physical read accounting.
