# GF6 receiver-aware transfer plans

Probe only the two explicitly authorized basis keys in a signed v3 batch.
Select an exact one- or two-basis XD program when a prepared receiver can
prove the required byte identities. Verify again during native import.
An unavailable basis routes through the existing exact CDC path.

Compare signed plain two-leg relay, existing v3, a precomputed
source-preferred closure, and receiver-aware selection on loopback.
Measure all request and response bodies per leg, requests, preparation
CPU, wall and actual verification. Include the 0/1/7/1000-edit controls,
empty, ordinary, unrelated and two-basis receivers, a truncated response,
and paced shaped RTT. Establish the crossover against the best option
rather than presenting one narrow seeded result as universal.
