# Z4-P6 reproduction (research only; production `zeros3.go` and `go.mod` are unchanged)

Go 1.27, Python 3.13 (numpy, pyarrow, zstandard, safetensors, gguf, onnx), clang 18.1.3 and clang 19.1.1, `git`.
Code: `testing-harnesses/z3/{semcore,semcas,graphcore,graphnorm,cmd/z4p6,cmd/p6extract,cmd/p6alias}`.

| package | role |
|---|---|
| `semcore` | **portable B3 core** (stdlib + `st`/`ggufz3`/`torchz3` parsers): descriptors, ops, recipes, `Backend` interface, streaming ingest, planner, root planner, verified-block ranges |
| `semcas` | research adapter: directory `Backend`, DEFLATE/Parquet extensions, container/columnar planners, cost models; re-exports `semcore` (`alias_gen.go`, generated by `cmd/p6alias`) |
| `graphcore` | **portable B4 core**: graph identities (`Graph`, compact `CGraph`), matcher, bitstream/LLVM/PDB/DEX encoders, reversible VM, recipes (resolver injected) |
| `graphnorm` | research adapter: CAS/archive cost models and simdelta resolver around `graphcore` |
| `cmd/p6extract` | mechanical single-file extractor with differential vectors and rehearsals |

```sh
go -C testing-harnesses/z3 build -o /tmp/z4p6 ./cmd/z4p6        # driver: ingest|replay|cost|roots|ranges|tiles|gen|graphbench|matchbench
# inputs (pins: ../b3/hf_pins.txt, results/b3_q4_pins.txt, results/b4_bitcode_pins.txt)
../b4/build_corpus.sh WORK/b4 && scripts/build_clang19.sh WORK/b4
scripts/b3_mem_sweep.sh   BIN HF OUT      # SmolLM2 family under memory limits (stores are byte-identical to B3's)
scripts/b3_scale.sh       BIN WORK OUT    # 0.4 / 1.9 / 6.4 GB synthetic related families, fresh-process replay + hashlib
scripts/b3_order.sh       NEW BASE HF WORK OUT   # input-order sensitivity: online fwd/rev, pre-P6 optimize, P6 root planner
scripts/b3_ranges.sh      BIN STORE HF OUT.jsonl # 4K/64K/1M ranges: unverified vs verified 4K/16K/64K blocks, per component kind
z4p6 tiles -rows 1536 -cols 576               # row-major vs tile-major root vs hot layouts for transposed ranges
scripts/b4_graph_bench.sh BIN OUT.jsonl       # reference vs shared vs compact identities (100k/1M/10M), matcher
scripts/orc_feasibility.py COLDIR             # bounded ORC probe
scripts/extract_all.sh    OUTDIR              # extraction of both cores + differential vectors + rehearsals (repo root)
scripts/qualify.sh        B4CORPUS            # gofmt/vet/build/tests/race/fuzz/production-unchanged (repo root)
python3 -I scripts/verify_replay.py BIN STORE OUT FILES...   # fresh-process replay checked with hashlib
```
`results/` holds the raw JSONL/JSON and text outputs of every table in the report.
