# Z4-P1A evidence: PUT compute pipeline

Report: [`../../results/Z4_P1A_PUT_COMPUTE.md`](../../results/Z4_P1A_PUT_COMPUTE.md). Driver, flags, content generator and byte-exact
verification are the unchanged Z4-P0 `p0bench` (`../p0/`); each repetition is a fresh store and process, and every PUT is replayed in a
fresh process and compared byte for byte.

| Path | Purpose |
|---|---|
| `scripts/build.sh ROOT OUT` | plain + P0-overlay-profiled production binaries and `p0bench` for the checked-out tree |
| `scripts/ab.sh OUT ROUNDS SCENARIOS name=dir...` | interleaved A/B runner: every round runs each scenario once per variant, alternating |
| `scripts/mkenv.sh NAME DIR "VAR=VAL..."` | variant dir whose binary wrapper exports `GOMAXPROCS` / `ZEROS3_INGEST_ABLATE` |
| `scripts/run_final.sh BASE FINAL` | the full set: matrix, GOMAXPROCS sweep, ablation, CPU profiles |
| `scripts/summarize.py FILE...` | median [min-max] throughput, CPU-s/GiB, cores, peak RSS, p50 per scenario and variant |
| `results/baseline_ffceb09.jsonl` | first baseline, 5 interleaved rounds, unmodified main `ffceb09` |
| `results/final_matrix.jsonl`, `final_gomaxprocs.jsonl`, `final_ablation.jsonl` | measurements of the final commit against the same baseline binary |
| `results/prof/*.txt` | compact CPU/alloc/block profile summaries (raw pprof not committed) |
| `results/small_ab*.jsonl` | 8-round re-measurements of the small-object cells (also order-swapped, and at GOMAXPROCS 1) used to rule out run-order bias |
| `results/P1A_TABLES.md` | tables generated by `scripts/report_tables.py` from the JSONL above |
| `results/matrix_c3.jsonl` | intermediate candidate (before the 32 MiB pipeline floor and early fsync); kept for the design history |

`ZEROS3_INGEST_ABLATE=nopipe,syncpublish,syncwrite,fullverify,noearlysync,pipemin=N,pipeslots=N` switches single mechanisms off
for these measurements only; it is not a supported tuning interface and production runs with none set.

Reproduce: `scripts/build.sh $PWD /tmp/p1a/final`, build the baseline the same way from `ffceb09`, then
`scripts/run_final.sh /tmp/p1a/base /tmp/p1a/final` (about 1.5 h; root not required, `drop_caches` is not used).
